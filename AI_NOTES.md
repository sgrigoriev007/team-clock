# Разработка с помощью ИИ

## Постановка задачи

По предоставленному скриншоту задания: создать с нуля небольшое веб-приложение для учёта рабочего времени сотрудников, используя ИИ для написания кода. Нужны добавление сотрудников, запуск/остановка таймера с описанием задачи, история и общее время каждого сотрудника за период, сохранение после перезапуска. Достаточно простого интерфейса; роли и авторизация не требуются. Используются только введённые данные. В README требуются запуск, инструменты ИИ, затраченное время и объяснение важных решений, включая повторный запуск таймера и пустой отчёт.

## Инструмент

OpenAI Codex в ChatGPT. Функции приложения работают без ИИ и внешних API. Секреты и токены в исходники не добавлялись.

## Основные решения

1. Один процесс Python и SQLite: минимальный порог запуска без зависимостей.
2. Хранить начало и конец, а не увеличиваемый счётчик: восстановление после перезапуска и независимость от вкладки браузера.
3. Ограничить активные задачи уникальным индексом: защита от двойного клика и параллельных запросов.
4. Считать пересечение интервалов с выбранными датами: корректные отчёты для ночных задач.
5. Показывать пустые состояния и ошибки в интерфейсе: отсутствие записей не считается ошибкой.
6. Использовать серверное время, DOM textContent и параметризованные SQL-запросы.

## Проверки

Автоматические тесты бизнес-логики и HTTP API находятся в `tests/test_app.py`. Они включают конкурентные запросы, восстановление состояния и задачи на границах периода. Порядок ручной проверки интерфейса указан в README. Локально прошли 13 автоматических тестов и проверка синтаксиса JavaScript. Через Playwright/Chromium проверены добавление двух сотрудников, независимые таймеры, сохранение после обновления страницы и остановка. Макет проверен при ширине 1440 и 390 px; ошибок JavaScript и горизонтального переполнения страницы после исправления не обнаружено. Docker недоступен, контейнерный запуск не проверен; CI-матрица подтверждается только после выполнения GitHub Actions.

## Время

Реализация выполнена в одной сессии совместной работы с Codex. Ориентировочно 20 минут календарного времени на подготовку, реализацию и локальные проверки в сессии 5 ноября 2026 года, плюс ожидание входа и публикация в GitHub. Это оценка времени работы с ИИ, а не человеко-часов самостоятельной разработки.

## Ограничения

Нет авторизации, редактирования/удаления записей и автоматического определения активности. Перезапуск сервера не останавливает активную задачу. Даты отчёта — UTC. Это сознательные ограничения небольшой демонстрации, а не заявленная готовность к production.
